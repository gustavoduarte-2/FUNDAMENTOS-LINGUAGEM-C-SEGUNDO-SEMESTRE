# FUNDAMENTOS-LINGUAGEM-C-SEGUNDO-SEMESTRE
Exercícios, algoritmos e projetos práticos desenvolvidos em Linguagem C durante o curso de Análise e Desenvolvimento de Sistemas (ADS). Focus em lógica de programação, estruturas de dados e gestão de memória.

💻 Algoritmos e Programação em Linguagem C
Status do Repositório: ⏳ Em desenvolvimento contínuo / Semestre Letivo

Este repositório é dedicado ao armazenamento, organização e documentação de exercícios, algoritmos e projetos desenvolvidos em Linguagem C durante o curso de Análise e Desenvolvimento de Sistemas (ADS).

🎯 Objetivo
O propósito deste espaço é registrar a evolução prática no aprendizado da linguagem C, consolidando a lógica de programação, o gerenciamento de memória e a resolução de problemas computacionais através de código estruturado.

🛠️ Conteúdos e Conceitos Abordados
Conforme o avanço das aulas, os códigos desenvolvidos neste repositório cobrem os seguintes tópicos:

Fundamentos e Sintaxe Básica: Entrada e saída de dados (scanf, printf), tipos de dados primitivos (int, float, char, double) e operadores aritméticos/lógicos.
Estruturas Condicionais: Tomadas de decisão com if, else if, else e switch-case.
Estruturas de Repetição: Laços de iteração usando while, do-while e for.
Vetores e Matrizes (Arrays): Manipulação de estruturas unidimensionais e multidimensionais.
Strings e Manipulação de Texto: Trabalhando com cadeias de caracteres e funções da biblioteca <string.h>.
Funções e Modulariedade: Criação de funções, passagem de parâmetros por valor e por referência.
Ponteiros e Memória: Entendimento de endereços de memória, ponteiros e alocação dinâmica.
Estruturas de Dados Básicas: Uso de struct para criação de tipos de dados personalizados.
